# CIS2203N_Orbello

## Mobile Development Repository

This repository contains all exercises, activities, and laboratory outputs completed for **CIS2203N – Mobile Development**. The project demonstrates the progression of Android application development concepts, version control practices, and the transition from Java-based Android development to Kotlin.

---

## Repository Overview

The repository is organized using multiple Git branches to isolate exercises, tasks, and feature implementations. Each branch represents a specific activity, exercise, or milestone completed throughout the course.

### Main Objectives

* Learn Android application development fundamentals
* Practice Git and GitHub version control workflows
* Implement Android user interfaces using XML layouts
* Develop Android applications using Java and Kotlin
* Understand Android Activities, Layouts, and Application Lifecycle
* Apply Kotlin programming concepts in Android development
